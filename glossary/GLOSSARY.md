# GLOSSARY
## Defined Terms and Concepts

---

## A

**Agent** — A specialized AI or software entity with defined responsibilities, constraints, and outputs. Agents do not compete; they specialize.

**Agent Context Package** — A subset of a Context Matrix tailored to a specific agent role, containing the information that agent needs to act.

**Agent Translation Layer** — The component of the Nexus Protocol that converts structured context into agent-specific formats.

**Architecture Decision Record (ADR)** — A documented decision about system architecture, including context, options, decision, rationale, and consequences.

## C

**Canonical Knowledge** — Validated, versioned understanding that has passed through the full knowledge lifecycle. The highest level of confidence in the system.

**Capability** — Something the system can do. A functional ability that may or may not be automated.

**Chief Architect** — The agent role responsible for system-wide structural coherence and architecture decisions.

**Clone the Repo, Become a Node** — The onboarding philosophy: anyone who clones the public skills repository and runs the system becomes a spoke in the collective mesh.

**Context Matrix** — The central data structure of the Nexus Protocol. A structured YAML document representing the current state of a domain, project, or mission.

## D

**Decision Lifecycle** — The 12-stage process through which ideas graduate from observation to protocol: Observation → Hypothesis → Proposal → Discussion → Experiment → Evidence → Implementation → Validation → Canonical Knowledge → Skill → Automation → Protocol.

**Doctrine** — The foundational principles, ontology, and governance defined in `quillyos-foundation`. Immutable without recorded decision.

## E

**ENDS Device** — The initial physical platform: an ENDS-derived modular handheld device that evolves into a distributed health/sensing/comms/research node.

**Evidence** — Observations, data, or experimental results. The raw material from which knowledge is derived.

**Execution Node** — An agent, workflow, or hardware device that acts on the knowledge layer (Layer 3).

## F

**Foundation** — The `quillyos-foundation` repository. Contains truth. Nothing executable. Only doctrine.

## G

**Governance Steward** — The agent role responsible for identity repository, evolution proposals, decision records, and approved doctrine.

## H

**Hand-in-Hand Philosophy** — Human-synthetic co-development. The system supports life rather than extracting from it.

**Hub-Spoke Model** — The network topology where the Protocol (not a person) is the hub, and execution nodes are spokes.

## I

**Ingestion Pipeline** — The automated process for capturing, normalizing, classifying, and integrating documents into the knowledge graph.

## K

**Knowledge Curator** — The agent role responsible for ingestion, deduplication, classification, cross-referencing, and knowledge graph maintenance.

**Knowledge Graph** — The structured network of entities, relationships, and knowledge records that forms the system's understanding.

**Knowledge Lifecycle** — The process every document passes through: Capture → Normalize → Cross Reference → Discussion → Implementation → Validation → Archived Knowledge.

**Knowledge Operating System** — What QuillyOS is. Not merely an AI OS, but a system for managing, versioning, and sharing understanding across all participants.

## L

**Layer 0 — Human Intent** — The steward's direction, ethics, and boundaries.

**Layer 1 — Nexus Protocol** — The translation layer that makes human intent machine-interpretable.

**Layer 2 — Knowledge / Reasoning / Memory** — The structured, versioned, searchable understanding layer.

**Layer 3 — Execution Nodes** — Agents, workflows, and hardware nodes that act on the knowledge layer.

**Layer 4 — Reality** — The physical world: hardware, markets, people, sensors.

## M

**Mesh Network** — The distributed network of nodes that communicate through the Nexus Protocol.

**Mission** — Why something exists. The fundamental purpose that justifies a project, agent, or capability.

## N

**Nexus Protocol** — The common language that every repository, agent, workflow, and hardware node speaks. Provides shared representation of reality.

**Node** — A physical or logical execution unit in the mesh network.

**Nothing Duplicates Doctrine** — The rule that no downstream repository may duplicate principles defined in `quillyos-foundation`.

## O

**Ontology** — The system of canonical object types (15 types) and relationships that forms the universal language of the ecosystem.

**Open Questions** — Known unknowns that are explicitly tracked and addressed.

## P

**PicoClaw** — The local cognition node. Persistent reasoning, document ingestion, skill execution, knowledge synthesis, memory retrieval, local automation, Git synchronization.

**Planned Obsolescence** — Rejected by the system. Every generation should enhance previous generations whenever possible.

**Protocol** — A defined communication or operation standard. A stabilized rule that enables interoperability.

**Protocol Over Platform** — The principle that the protocol (shared representation) is more important than any specific implementation.

## Q

**QuillyOS** — The knowledge operating system. An operating framework rather than software. Manages knowledge, coordinates agents, orchestrates workflows, abstracts hardware, evolves protocols.

## R

**Relationship** — A typed connection between objects in the ontology. The glue that makes the knowledge graph traversable.

**Revenue** — Fuel, not destination. Sustains research and infrastructure.

## S

**Session Handoff** — The mechanism for passing structured context between sessions, enabling continuity across agents and time.

**Shared Understanding Over Shared Memory** — The principle that structured context packages replace chat history as the primary communication mechanism.

**Simplex Unification** — The format for shared context: Mission, Current Architecture, Known Evidence, Open Questions, Constraints, Dependencies, Objectives, Current Milestones.

**Skill** — A deployable, versioned capability. A packaged unit of functionality that can be loaded and executed.

**Spoke** — A node in the mesh network that connects to the hub (Protocol).

**Steward** — The human who maintains Layer 0 intent, ethics, and strategic direction.

## U

**Upward Reference** — The rule that lower repositories may reference higher repositories, but never the reverse.

## V

**Vision** — What the future looks like. A long-term aspirational description of the desired state.

*This glossary is a living document. Propose new terms or refinements through the Decision Lifecycle.*
