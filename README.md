# QuillyOS Foundation

> **Nothing executable. Only truth. Everything else references this repository.**

This is the canonical foundation repository for the QuillyOS ecosystem. It contains the vision, protocol definitions, ontology, governance structures, and architectural principles that all other repositories derive from.

## Repository Structure

```
quillyos-foundation/
├── FOUNDATION.md              ← Start here. The master document.
├── vision/                    ← Long-term vision documents
├── protocol/                  ← Nexus Protocol specifications
├── ontology/                  ← Canonical object types and relationships
├── governance/                ← Agent roles, mesh governance, stewardship
├── identity/                  ← Node identity, reputation, access patterns
├── principles/                ← Core design principles and ethics
├── architecture/              ← System architecture, repository hierarchy, hub-spoke model
├── roadmap/                   ← Milestones, phased evolution
├── decision_records/          ← ADRs and decision lifecycle documentation
├── glossary/                  ← Defined terms and concepts
├── ethics/                    ← Ethical framework and boundaries
├── references/                ← External references, citations, prior art
├── session_briefs/            ← Session handoff briefs (living)
└── scripts/                   ← Handoff and utility scripts
```

## Getting Started

1. Read `FOUNDATION.md`
2. Review `protocol/NEXUS_PROTOCOL_SPEC.md`
3. Check `architecture/REPOSITORY_HIERARCHY.md`
4. Understand `ontology/CANONICAL_OBJECT_TYPES.md`

## Contributing

```
Observation → Hypothesis → Proposal → Discussion → Experiment → Evidence → Implementation → Validation → Canonical Knowledge
```
