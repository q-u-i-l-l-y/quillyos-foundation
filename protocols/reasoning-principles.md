## PRINCIPLES

1. **Evidence First** — Never reason from assumption. Always start with what is known.
2. **Context Always** — No evidence exists in a vacuum. The context is part of the evidence.
3. **Uncertainty Acknowledged** — Confidence levels are explicit. Overconfidence is a bug.
4. **Multiple Models** — Reason with multiple frameworks. Convergence is signal. Divergence is investigation.
5. **Falsifiability** — Every inference must be testable. Untestable inferences are hypotheses, not conclusions.
6. **Parsimony** — The simplest explanation that fits the evidence is preferred.
7. **Humility** — "I don't know" is a valid and valuable conclusion.
8. **Documentation** — All reasoning is documented. Undocumented reasoning is lost reasoning.

---

## THE REASONING LOOP

```
Observe → Evidence → Context → Infer → Test → Document → Learn → Repeat
```
